This is a **behavioral** comparison against published original Java sources, not a claim that all ported modules are fully equivalent. The original repositories are marked **All Rights Reserved**. The Sunrise implementation is independent and must not copy original source code.

## Validation policy

- A module is not **1:1** merely because it compiles or because its control appears in the GUI.
- Static tests exercise expected code wiring. Wasmtime tests exercise only scenarios for which `tools/sandbox/sunrise_qol_smoke.rs.txt` provides a real host fixture.
- The current sandbox verifies loot count and select interaction hooks but **does not simulate all world updates, multiplayer prediction, or actual visual door animation**.
- For any module requiring private engine hooks, a new public Sunrise API or an upstream change is needed before exact 1:1 behavior can be certified.
- Keep all modules disabled by default, preserve existing stored settings and leave Sound Controller / Individual Sounds excluded.
